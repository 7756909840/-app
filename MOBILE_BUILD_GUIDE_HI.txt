मोबाइल से APK बनाने का आसान तरीका (GitHub Actions)

यह ZIP APK-ready source project है। APK GitHub के cloud computer पर बनेगा; इस चैट में सीधे APK compile करना संभव नहीं है।

1) Chrome में github.com खोलें और मुफ्त account बनाएं / sign in करें।
2) नया repository बनाएं: fresh-shop-app (Public या Private)।
3) इस ZIP को फोन में Extract करें।
4) GitHub repository में Add file > Upload files चुनें।
5) Extract किए हुए FreshShopAndroid फोल्डर के अंदर की सभी फाइलें और .github फोल्डर भी upload करें। ध्यान दें: .github hidden हो सकता है; उसे भी upload करना जरूरी है ताकि cloud build शुरू हो।
6) Commit changes करें। GitHub Actions में workflow build शुरू करेगा।
7) Repository के Actions tab में "Build Fresh Shop APK" खोलें। सफल होने पर नीचे Artifacts में "Fresh-Chicken-Mutton-Shop-APK" मिलेगा।
8) Artifact ZIP डाउनलोड करके Extract करें। उसके अंदर app-debug.apk होगा। उस APK को खोलकर Install करें।

अगर .github hidden folder फोन के file manager में नहीं दिखता या upload करना मुश्किल हो, तो GitHub में Actions workflow file manually add करनी होगी; मुझसे स्क्रीनशॉट भेजकर अगला कदम पूछें।

सुरक्षा/डेटा: APK install होने के बाद ऐप फोन में ऑफलाइन चलेगा। अनइंस्टॉल या app data clear करने से local entries मिट सकती हैं; Backup से JSON export करते रहें।
