FRESH CHICKEN & MUTTON SHOP — Android Studio project

महत्वपूर्ण: यह Android APK बनाने के लिए प्रोजेक्ट सोर्स है, तैयार APK फाइल नहीं।
इस वातावरण में Android SDK/Gradle build उपलब्ध नहीं है, इसलिए यहां APK compile नहीं किया जा सका।

APK बनाने के कदम:
1. कंप्यूटर पर Android Studio इंस्टॉल करें।
2. Android Studio में इस ZIP को Extract करके Open करें (FreshShopAndroid फोल्डर चुनें)।
3. Gradle sync पूरा होने दें और Android SDK Platform 35 इंस्टॉल करें, अगर मांगे।
4. Build > Build Bundle(s) / APK(s) > Build APK(s) चुनें।
5. APK आमतौर पर app/build/outputs/apk/debug/app-debug.apk में बनेगा।
6. APK फोन में भेजकर install करें। फोन में जरूरत पड़ने पर 'Install unknown apps' अनुमति दें।

ऐप ऑफलाइन WebView में चलता है और एंट्री इसी फोन के ऐप डेटा में सेव होती है।
ऐप डेटा साफ/अनइंस्टॉल करने से एंट्री मिट सकती है। ऐप के Backup सेक्शन से नियमित बैकअप लें।
